# Farm Management System — Salesforce DX

This repository package is based on the supplied Farm Management System project specification.

## Project
A Salesforce-based Farm Management System for managing:
- Farms
- Crops
- Farmers
- Buyers
- Reports
- Dashboards
- Validation
- Security and sharing

## Source
The implementation requirements are derived from the supplied 51-page project document.

## How to use
1. Extract the ZIP.
2. Open the extracted folder in VS Code.
3. Authenticate to a Salesforce Developer Org.
4. Deploy the metadata using Salesforce CLI.
5. Create/insert sample data.
6. Open the Farm Management System Lightning App.
7. Verify reports and dashboards.

## Important
Salesforce metadata can be stored in GitHub, but the actual Salesforce org is where the application runs. Never commit passwords, tokens, or personal credentials.

See `PROMPT.md` for the complete build specification.
