# Setup

1. Install Salesforce CLI.
2. Authenticate to a Salesforce Developer Org.
3. Open this folder in VS Code.
4. Deploy the `force-app` source to the org.
5. Resolve any org-specific metadata differences reported by Salesforce.
6. Configure any items explicitly marked as manual in README/PROMPT.
7. Load fictional sample data.
8. Verify the Lightning App, reports, and dashboard.

Do not commit credentials or authentication files.
